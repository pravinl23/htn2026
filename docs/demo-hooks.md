# Demo surfaces

The demo package contains fictional local pages used for development and tests. Start it with:

~~~bash
pnpm --filter @shabang/demo dev
~~~

It is intentionally separate from the native product UI and exists so form and write behavior can be rehearsed without touching a real service. The old invoice, mail, calendar, and workflow hook catalogue documented a removed browser/loop demo direction; it is no longer a supported Shabang capability.
