# Historical architecture note

This file formerly compared the extension-based form/loop direction with an atomic-workflow direction. Neither is the supported Shabang product direction now.

Shabang is a native macOS app. The old Chrome extension is isolated in attic, and batch loops, cloud execution, and atomic workflows are not part of the active desktop flow. For the current design, read [architecture](architecture.md) and [the native pipeline](desktop.md).
