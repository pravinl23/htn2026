# Ghost

Cursor Tab for your whole computer. Ghost predicts your next action and shows it as a ghost cursor and ghost text; press Tab to accept. Do a task twice and Ghost does the rest.

Built at Hack the North 2026. Build instructions for the autonomous builder live in `CLAUDE.md`, the roadmap in `PLAN.md`, the run log in `PROGRESS.md`, and the morning handoff in `MORNING.md`.
